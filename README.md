# 山河輿圖

把三國名城一座座丟進箱子，相鄰的城碰在一起就會合併成一整片真實地圖。天下大勢，分久必合。

單一 HTML 檔，不用安裝、不用網路，開啟 `index.html` 就能玩。

## 玩法

- 移動滑鼠（或手指）決定落點，按一下放下城池。
- 相鄰的城在正確的交界側碰到，會合併並縮小，騰出空間。
- 堆太滿會失敗；卡住時可以搖一搖（有冷卻時間）。
- 達成各種相連組合可解鎖成就，每局重新計算，歷史收藏存在瀏覽器裡。

## 說明

- 城池輪廓由現代行政區界線近似而成，並非漢末真實邊界。
- 成就的史事文字僅供娛樂，史實請以史書為準。
